# Slayer Tracker

Slayer Tracker is a RuneLite sidebar plugin for tracking Old School RuneScape Slayer assignments. See your current task, Slayer points, estimated kills, and observed task history in one place.

## Features

* See your current assignment, starting and remaining counts, and task progress.
* Track your current Slayer points and observed increases and decreases.
* See observed assignments, completed tasks, and explicit skips.
* View estimated kills and Slayer XP for each assignment, with individual monster breakdowns.
* Search and sort assignment cards in the Monsters view.
* Review recent individual tasks in History, including their estimated kills, points, and Slayer XP.
* Keep tracked statistics separately for each RuneLite character and game-mode profile.

## Getting started

1. Find and install **Slayer Tracker** through RuneLite's Plugin Hub.
2. Log in and open the **Slayer Tracker** sidebar.
3. View your current task and Slayer statistics in **Overview**.
4. Use **Monsters** to explore assignment totals and **History** to review individual tasks.
